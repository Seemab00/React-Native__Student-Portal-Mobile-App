# Student Portal App with Motivational Quotes

## 📌 About

**Student Portal App** is a React Native mobile application developed for the Mobile App Development course. It provides students with a comprehensive portal featuring motivational quotes, upcoming events, an interactive calendar, and a complete settings page with animated UI elements.

---

## ✨ Features

### Core Features
- Student dashboard with motivational quotes
- Upcoming events section with View More/View Less toggle
- Interactive calendar with current date highlighting
- Animated splash screen with gradient and floating emojis
- Complete settings page (Help & Support, Contact Us, Notifications, Messages, Profile)
- Marquee text for announcements
- Animated code screen

### Extra Features (All Implemented)
- Animated Splash Screen (moving gradient, floating emojis)
- Home Screen with Upcoming Events section
- Interactive Calendar Component
- Animated Code Screen
- Complete Settings Page (Help & Support, Contact Us, Notifications, Messages, Profile)
- Marquee State (continuous scrolling text)
- Dynamic theme support (Text, Inputs, Buttons)

## 🚀 Quick Start

```bash

# Install dependencies

# Start the app
npx expo start
```
